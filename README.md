# Moon Toybox

Three.js-библиотека перламутровых SDF-объектов, кратеров и лучевых бликов.

## Состав

- `LIBRARY.md`
- `PUBLICATION.md`
- `fields`/
- `icons`/
- `lib`/
- `package.json`
- `pearl-material.js`
- `pearl-rays.js`
- `sdf-pearl.js`
- `sdf-worker.js`

## Подготовка и запуск

Манифесты зависимостей в этой копии:
- [package.json](package.json)

Объявленные npm scripts: отсутствуют. Перед запуском проверьте `package.json`; установка и scripts при публикации не выполнялись.

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.

## Ограничения снимка

- Публичная source-only копия. Truck/teddy и все производные assets исключены: права распространения не подтверждены в LIBRARY.md. Доступны moon/knot и геометрические поля sphere/ring. Оригиналы не изменены. Новая лицензия не назначается; для сторонних библиотек действуют их лицензии.
- При оформлении репозитория приложение не развёртывалось, платежи и внешние API не запускались; тесты не перепроверялись.
